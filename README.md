# 足球人生 · Football Life

一个纯前端、无依赖的足球生涯模拟游戏。从 16 岁起步，通过训练、比赛、转会和赛季推进走向退役。

## 运行方式

直接双击 `index.html` 即可（使用普通 `<script>`，兼容 `file://`）。

如果希望用本地服务器：

```powershell
python -m http.server 8000
# 然后打开 http://localhost:8000
```

## 目录结构

```
Game/
├─ index.html          页面结构：创建页 / 主界面四宫格 / 各功能弹层
├─ assets/
│  └─ style.css        全部样式
├─ js/
│  ├─ data.js          静态配置：属性、训练、比赛事件、成就、文案
│  ├─ engine.js        仿真引擎：状态、成长、比赛、赛季、转会、存档
│  └─ ui.js            UI 层：DOM 绑定、面板、渲染、比赛逐步播放
└─ README.md
```

脚本按 `data.js → engine.js → ui.js` 顺序加载，使用全局作用域共享状态与函数；这样无需构建工具，也避免了 `file://` 下 ES Module 的跨域限制。

## 主要可调位置

### 属性与成长（`js/data.js`）

- `ATTRS` / `ATTR_LABEL` / `ATTR_GROUPS`：12 项属性，分为技术、精神、身体三组。
- `ATTR_START`：各位置初始能力区间（1–20）。
- `ATTR_WEIGHTS`：位置综合能力权重，每行合计 1.0。
- `ATTR_XP_BASE` / `XP_GROWTH`：每项属性各自的升级经验基数与成长曲线；界面不显示经验数字。
- 属性面板只显示数值：1–5 灰、6–10 白、11–15 黄、16–20 绿。

### 训练（`js/data.js` + `js/engine.js`）

- `TRAIN_CATS`：技术、射门、防守、速度、体能五个训练模块。
- `TRAIN_POS_WEIGHTS`：同一模块对不同位置的属性加成权重，权重越高获得经验越多。
- `INTENSITIES`：轻度 / 普通 / 强化特训的消耗与收益倍率。
- `TRAIN_READY`：训练后下一场开场体能目标——轻度 100%、普通 95%、强化 82%。
- 改动训练逻辑时优先调整 `TRAIN_POS_WEIGHTS` 与 `ATTR_XP_BASE`，不要改 UI。

### 体能（`js/data.js` + `js/engine.js`）

- `prepareMatchFitness()`：赛前恢复。本周未训练恢复到 100%，普通训练 95%，强化训练 82%。
- `matchFullCost()`：满场体能消耗，按位置与耐力属性计算；比赛按实际出场分钟扣除。
- 训练顺序为“先扣训练消耗，再恢复到下一场开场目标”，不会出现先回满再扣训练导致比赛体能偏低的问题。

### 比赛（`js/data.js` + `js/engine.js`）

- `POS_EVENT_WEIGHTS`：各位置抽到扑救/防守/传球/进攻的概率。
- `MATCH_EVENTS`：通用关键事件池及所需属性权重。
- `POS_SPECIAL_EVENTS`：门将专用传球/出击事件。
- `FILLER_TEXTS`：非关键点场面文案。
- `LEAGUE_AVG`：各联赛平均能力，用于计算事件成功率。
- `simMatch()`：返回结构化 `beats`，由 UI 逐环节播放；每半场 5 次关键点，实时评分、比分、体能消耗、换人判定。
- 替补席球员有概率在 56–80 分钟替补登场；完全未登场时评分固定 6.0，且不计入场均评分。
- 换人规则：过了半场后，连续两个关键点实时评分低于 6.0，或关键节点体能低于 40，即被替换下场。

### UI / 页面

- `index.html`：主界面四个方格（属性 / 训练 / 数据 / 生涯）、底部比赛操作条。
- 成就入口在右上角 🏆 按钮，点击打开独立弹层。
- `fitTiles()`（`js/ui.js`）：按可视高度收缩四宫格，主界面不会出现纵向滚动。
- 比赛层一次只显示当前环节：非关键点显示场面话与等待动画；关键点先显示时间与叙述，延迟后显示结果；进球/助攻/扑救有强调动画。
- 底部“模拟下一场”会自动完成一次平均训练（普通强度）并快速结算。

## 存档

使用浏览器 `localStorage`，键名为 `football_life_save_v1`。旧版本存档会在读取时自动从 20–99 制换算到 1–20 制，并把旧的 6 属性扩展为 12 属性。

## 开发提示

- 修改静态配置优先只改 `js/data.js`。
- 修改行为逻辑改 `js/engine.js`，不要把 DOM 操作写进引擎。
- 修改展示、面板、按钮交互改 `js/ui.js`。
- 三个脚本均为经典脚本，新增文件时保持加载顺序并在 `index.html` 中追加 `<script src="...">`。
